Heka Hoods · Box Order Desk

Box & pallet plan, from pieces you type in

Enter each piece’s depth, length and shape by hand. Nothing is uploaded, read from a file, or sent anywhere — this page has no server behind it. Boxes and pallet load are computed instantly, right here in the browser.

1 · Job

H Sections and Joiners aren’t computed — read them straight off the job card’s own “Page details” table. “Hoods” on the DWO is filled in automatically as your piece count below. “Number of hoods” is just a shortcut: type a count and that many empty rows open below at once, instead of clicking “+ Add piece” one at a time — it only adds rows, never removes ones you’ve already filled in.

2 · Pieces

Straight — a plain run, no corners. Covers most jobs, so every new row starts here.

L-shape (1 return) — one welded corner on this piece.

U-shape / closed loop (2 returns) — two welded corners on this piece, e.g. a leg inside a full surround.

Tapered — non-constant depth / non-standard shape.

Angled corner — mitred at an angle (5/10/15/30/45°) rather than a square weld.

Any of these forces that piece into its own box on dispatch — same as a depth over 600mm.

The separate Express checkbox is a different thing: it marks a piece as part of the Express range (Heka Hoods’ stock catalog — depth 300/450/600mm, length 1200 or 2400mm) rather than a custom job. Express pieces always go 1 per box regardless of Hood type.

Box size = that box’s hood depth + 200mm (width), 170mm height, or 260mm if the box has a return. Boxes stack up to a 1.2m total height (pallet + boxes) — with a tighter cap for deep hoods (HH900+: max 4 high, HH1200+: max 2 high). Max 2 pallets end to end per row (a longer box overhangs, centered, rather than getting a 3rd pallet). Weight is a flat 15kg/box placeholder. All placeholder numbers carried over from the main Box Order tool — not final.
